# DESCRIPTION

The Penetration Testing Toolkit is a Python-based cybersecurity project developed to perform basic penetration testing and security assessment tasks. The toolkit combines multiple security tools into a single menu-driven application to help users understand the fundamentals of ethical hacking and network security testing.

The project includes modules such as a Port Scanner, Banner Grabber, and Brute Force Demo. These modules help identify open ports, retrieve service banners, and simulate password brute-force attacks in a controlled and educational environment.

The toolkit is designed strictly for learning purposes and authorized security testing only.

# MODULES INCLUDED

## 1. Port Scanner
Scans commonly used ports on a target system and identifies open ports.

## 2. Banner Grabber
Connects to a service and retrieves banner information such as server or software details.

## 3. Brute Force Demo
Simulates password brute-force attacks using a predefined or user-provided wordlist.

---

# HOW THE TOOL WORKS

1. User launches the toolkit
2. A menu of security modules is displayed
3. User selects a module
4. Target information is entered
5. The selected security test is performed
6. Results are displayed on the screen
